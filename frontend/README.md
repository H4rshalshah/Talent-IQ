# Talent-IQ Frontend

React + Vite frontend for the Talent-IQ interview platform.

See the [root README](../README.md) for full setup instructions, environment variables, and architecture.

## Quick start

```bash
npm install
cp .env.example .env   # fill in Clerk / API / Stream values
npm run dev            # http://localhost:5173
```

## Scripts

- `npm run dev` — Vite dev server
- `npm run build` — production build
- `npm run lint` — ESLint
- `npm run preview` — preview the production build
